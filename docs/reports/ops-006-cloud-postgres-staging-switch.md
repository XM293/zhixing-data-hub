# 腾讯云 PostgreSQL staging 切换验证

日期：2026-09-08  
关联任务：`OPS-006`  
结论：客户 staging 应用已从服务器 SQLite 切换到腾讯云 PostgreSQL，数据一致性与应用链路通过。

## 实施范围

- 复核应用服务器主机名、公网 IP 和腾讯云数据库内网路由。
- 使用管理身份完成 PostgreSQL 真实认证。
- 创建独立业务库和最小权限应用角色，业务角色不具备管理类权限。
- 备份 SQLite 和运行环境配置，以线上稳定发布版迁移结构。
- 通过单一事务将 SQLite 业务数据迁入 PostgreSQL。
- 将 API 和 Worker 切换到同一云数据库，关闭应用启动时自动迁移和开发种子。
- 修复 Nginx 旧默认站点软链接抢占请求的部署问题。

## 运行边界

- 云数据库当前为 PostgreSQL 11.22，已证明兼容当前服务器发布版；项目正式目标仍为 PostgreSQL 16，后续升级需运行最新迁移和全量回归。
- 当前环境为 `staging`，文件资产暂时使用服务器本地目录。
- HTTPS、长期 SSH 密钥、关闭 root 密码登录、正式 Redis 和正式知识/记忆 Provider 不在本次数据库切换范围内。
- 运行凭据只存在服务器 root-only 环境文件；本报告和仓库不保存任何密码或连接密钥。
