# M0 产品全景原型验收报告

## 1. 当前结论

产品负责人未接受纯静态产品全景 v0.1，原因是页面演示感过强、视觉不足以代表企业 AI 数据中心，且无法证明数据库、外部接入和跨模块运行关系。此前“已达到验收状态”的结论撤销。

按 ADR-006 启动数据驱动重做：先交付持久化数据库、第三方电商沙箱、新视觉系统和企业数字孪生首页，再逐中心替换静态页面。`UIA-006` 回到阻塞状态，`DOM-001` 继续保持阻塞。

当前新增验收切片包括：

- Alembic 管理的持久化数据库和 PostgreSQL/MinIO 本地编排；
- 原始记录、映射版本、标准实体、指标快照和同步批次；
- 独立 HTTP 第三方沙箱及正常、延迟、部分失败、连接失败场景；
- 数据库驱动的 Three.js 企业数字孪生首页；
- 3D 节点选择、链路状态、经营指标、运行事件和手动同步。

## 3. 可复现演示故事

### 故事 A：制度更新影响分身回答

1. 进入“知识中心 / 制度版本”，发布绩效制度 v3。
2. 进入“分身中心 / 记忆审核”，拒绝与新制度冲突的旧记忆。
3. 打开企业助手，询问“9 月退款率如何考核？”。
4. 回答保持 v2 为当前有效版本，同时说明 v3 的未来生效时间；证据区显示冲突记忆已拒绝。

### 故事 B：经营异常进入数字会议

1. 进入“智能分析 / 店铺诊断”。
2. 查看 GMV、广告 ROI、库存和退款率事实，区分分析与建议。
3. 进入数字会议，查看 CEO、运营和财务分身的独立观点与保留分歧。
4. 形成带证据快照、预算上限和停止条件的决策包。

### 故事 C：会议结论进入人工审批

1. 从会议决策包进入“行动中心 / 审批队列”。
2. CEO 视角只能查看，审批按钮不可用。
3. 切换部门经理视角，由指定审批人批准。
4. 页面显示模拟台账、幂等键和完整时间线，明确未调用外部系统。

### 故事 D：客服辅助回复与人工接管

1. CEO 直达客服详情时显示 403；切换客服视角后获得本人会话范围。
2. AI 读取订单、物流和客服制度生成回复草稿。
3. 100 元补偿超过客服授权，草稿不承诺金额并提示风险。
4. 客服将会话转人工，列表与详情状态同步更新。
