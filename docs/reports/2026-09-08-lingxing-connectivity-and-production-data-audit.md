## 2. 官方协议确认

领星开放接口当前要求：

1. API 基址为 `https://openapi.lingxing.com`；
2. Token 接口使用 `multipart/form-data` 提交 AppID 与 AppSecret；
3. 业务请求携带 `access_token`、`app_key`、秒级时间戳和按全部参数生成的签名；
4. 签名按参数 ASCII 排序、拼接、MD5 大写、AES/ECB/PKCS5Padding 加密，并在传输时 URL 编码；
5. 签名有效期为 2 分钟，必须逐请求生成，不能缓存；
6. refresh token 有效期为 2 小时且只能使用一次；
7. 限流按 `AppID + 接口 URL` 使用令牌桶，接口文档会分别声明桶容量；
8. IP 白名单只接受公网 IP，不接受域名。

## 3. 当前生产库数据基线

云 PostgreSQL 当前有 135 张业务表。审计结果如下：

- `sync_runs`、`source_records`、`business_entities`、`metric_snapshots`、`data_scope_mappings` 均为 0 行；
- 规范订单、订单行、退款、库存、广告、客户主档和客户触点事实均为 0 行；
- 4 个 `ExternalSystem` 全部是从开发种子迁入的测试来源，尚未执行过同步；
- 非空数据合计 543 行，主要由权限目录、演示组织和账号、知识与记忆样例、客服样例、评测、工具与 Skill、数字孪生场景组成；
- 当前只有 1 个演示集团、1 个演示企业和 1 个“集团本部”业务单元；`SourceBinding` 与集团范围授权尚无生产数据。

因此，“清测试数据”不是删除已有经营事实，而是一次受控的生产租户引导与演示种子退场。直接 `TRUNCATE` 或删除整个数据库会误删权限、菜单、字典、工具、Skill 和登录能力。

## 4. 当前阻断项

真实同步前必须先解决：

- 数据中心同步入口和多个领域服务仍引用演示企业常量；代码中存在 120 处演示企业、集团或名称硬编码；
- `synchronize` 仍在 API 请求内执行并固定写入演示企业，不能用于集团生产接入；
- 当前连接器注册表只注册测试连接器，尚无领星认证、签名、分页、限流和游标实现；
- 当前 `ConnectorBatch` 一次把整个批次放入内存，不适合数百店铺和多年度数据；
- 现有金额字段以“分”命名，没有完整表达多币种、原币、集团本位币和汇率版本；
- 集团模型已建表，但集团级跨企业授权、上下文切换、合并查询和来源归属尚未形成闭环；
- 用户只提供了项目名称，尚未提供集团名称、法定子公司名称与内部编码，不能把项目名称擅自当作法人企业名称。

详细改造以 `docs/development/10-lingxing-erp-real-data-and-group-rollout-plan.md` 为准。
