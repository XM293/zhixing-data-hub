# ADR-010：受治理角色记忆与运行上下文

- 状态：Accepted
- 日期：2026-08-28
- 关联任务：`MEM-001`、`MEM-002`、`MEM-003`、`MEM-004`、`MEM-006`

## 背景

管理者聊天同时包含事实、临时判断、偏好、表达方式和过期规则。直接把聊天切片写入向量库会让旧制度、随口讨论和个人隐私在没有审核的情况下进入分身回答，并且无法解释某次回答到底使用了哪条记忆。

## 决策

1. 原始聊天、记忆候选和已审核长期记忆使用不同表和状态。
2. 记忆审核与激活分离；批准只表示内容被接受，激活才允许参与推理。
3. 与正式制度冲突的候选可以保留为历史，但永远不能激活。
4. 平台管理员负责资料导入，角色负责人负责审核与退役，二者权限分离。
5. 长期记忆以不可变版本保存；退役只关闭有效区间，不删除历史。
6. 每次回答将实际使用的长期记忆写入 `agent_run_context_items`，并与正式知识证据分开展示。
7. 正式制度和经营事实始终优先；记忆只能补充管理偏好、表达方式和经验。
8. TencentDB-Agent-Memory、Mem0 和后续 provider 只承担抽取/召回适配，不拥有审核状态和业务版本真值。

## 后果

系统可以从聊天中积累管理经验，同时保留人工责任、原始依据和运行可复现性。代价是需要维护显式审核队列、状态机和更多存储对象；但这是让数字分身可控、可纠错、可在企业内部长期使用的必要成本。
